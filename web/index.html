Regex match generator

Regular expressions define languages over alphabets. This tool enumerates the strings in such a language. Since regular expressions typically describe infinite languages, the enumeration must be bounded by a maximum word length and a finite alphabet. The generator uses the regular expression syntax supported by Rust’s regex crate.

Source on GitHub



Use Rust's regex syntax. Add ^ and $ to enumerate the whole match.



The alphabet is used to build candidate strings; the regex filters them. For example, abc means generated output can only contain a, b, and c.

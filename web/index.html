Regex match generator

Regular expressions define languages over alphabets. This tool enumerates the strings described by a regex. For infinite languages, use a word limit or maximum word length to bound the output.

source

Use Rust's regex syntax. Add ^ and $ to enumerate the whole match.

The alphabet is used to build candidate strings; the regex filters them. For example, abc means generated output can only contain a, b, and c.

Required for unlimited searches over infinite languages.
